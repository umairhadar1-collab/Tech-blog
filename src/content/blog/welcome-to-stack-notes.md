This is a sample post. Replace it with your own first article. It shows the structure I suggest for every AI post, so readers know what to trust.

## 1. Say what you tested

Put the tool, the model and the date at the top. AI tools change every month, so a post without a date is hard to trust.

## 2. Show the exact prompt

```text
Build a responsive blog home page in Astro.
Use CSS variables for colors, no CSS framework,
and keep each component in its own file.
```

## 3. Show the real result

Paste the output or a screenshot. Say what was good and what you had to fix by hand.

## 4. Say what you checked

If AI wrote code, list how you tested it. If AI helped you write the text, say so and say what you verified yourself.

## 5. Update old posts

Add a `lastUpdated` date to the top of the file when something changes. It appears at the bottom of the post.
